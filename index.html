홈 화면에 설치하면 브라우저 주소를 입력하지 않고 바로 열 수 있습니다.

현재 웹 앱 모드로 실행 중입니다.

Safari에서 설치

  1. 배포된 STUDY LEAGUE 주소를 Safari에서 엽니다.
  2. 공유 버튼을 누릅니다. 버전에 따라 페이지 메뉴에서 공유를 선택합니다.
  3. ‘홈 화면에 추가’를 선택합니다.
  4. ‘웹 앱으로 열기’ 옵션이 있다면 켜고 ‘추가’를 누릅니다.

삼성 갤럭시 · Android

직접 설치가 지원되는 상태라면 앱 설치 버튼을 한 번 눌러 설치 창을 열 수 있습니다.

  1. Chrome: 오른쪽 위 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
  2. 삼성 인터넷: 메뉴(≡) → 페이지 추가 → 홈 화면 또는 지원되는 앱 설치 항목.
  3. 설치 또는 추가를 확인합니다. 메뉴 이름은 브라우저 버전에 따라 다를 수 있습니다.

PC / Mac에서 설치

  1. Chrome 또는 Edge에서 배포된 포털을 엽니다.
  2. 주소창의 설치 아이콘 또는 브라우저 메뉴의 앱 설치 항목을 선택합니다.
  3. Mac Safari는 지원 버전에서 파일 메뉴의 ‘Dock에 추가’를 이용할 수 있습니다.
  4. 설치 메뉴가 없으면 브라우저 북마크로 등록할 수 있습니다.

이것은 앱스토어 앱이 아닌 웹 앱입니다. 과목별 사이트는 인터넷 연결이 필요하며, 다른 도메인으로 이동하면 별도 브라우저 화면이 열릴 수 있습니다.
